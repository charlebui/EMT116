# EMT 116 — GitHub Pages package

This package contains the current static website, including the Study tab, outside-source supplement sections, A&P matching, and the latest question revisions.

## Local preview

Run python3 -m http.server 8000 from the extracted directory, then open http://localhost:8000. Do not open index.html directly as a file; the app fetches chapter and study JSON.

Progress is stored in the browser on the current site origin.
